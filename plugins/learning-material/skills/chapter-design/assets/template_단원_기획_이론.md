## 학습 목표

> 이 단원을 마친 뒤 수강생이 할 수 있어야 하는 것을 "~~할 수 있다" 형태로 1~~2문장으로 작성해주세요. 단순한 이해보다는 구체적인 행동이나 결과물 수준으로 표현하면 좋습니다.

## 도입 내러티브 (Hook)

> 흥미로운 문제 상황을 제시하여 호기심을 유발할 수 있는 내러티브를 1~2문장으로 작성해주세요.

## 학습 개요

> 이번 단원에서 다룰 학습 개념을 작성해주세요.
>
> - **유형**: 학습 개념의 학습 방식입니다.
>   - `강의`: 주강사가 교재를 활용해 직접 설명하는 학습 방식입니다.
>   - `실습`: 수강생이 직접 해결해보고, 주강사가 이후에 해설하는 학습 방식입니다. 한 실습 항목은 문제 해결과 강사 해설을 포함해 1.5시간 이내로 편성합니다. 긴 실습은 수행 단계나 확인할 개념에 따라 나눕니다.
> - **학습 우선순위**: 이론은 기본과 심화로만 구분하며 필수는 사용하지 않습니다. 기본 항목의 제목은 `[{유형}] {개념}`으로 쓰고, 심화 항목만 `[{유형} | 심화] {개념}`으로 표시합니다.
>   - `기본`: 모든 수강생이 학습하는 기본 개념입니다.
>   - `심화`: 학습 성취도가 우수한 경우 추가로 학습하면 좋을 개념입니다. 강의를 통해 직접 가르치기 보다는 수강생이 스스로 학습할 수 있게 질문을 던지는 방식으로 학습합니다.
>
> - \*\*내러티브 및 연결성 (Why & How)\*\*:
>   - 첫번째 개념: 단원 도입부의 문제 상황을 해결하기 위해 이 개념이 왜 필요한지 설명합니다.
>   - n번째 개념: 앞선 개념의 한계점이나, 그 개념을 바탕으로 새롭게 생겨난 질문을 던지며 자연스럽게 도입할 수 있는 내러티브를 정의합니다.
>   - 결론: 이 단원에서 문제를 해결했지만, 또 다른 새로운 문제가 발생함을 암시하며 다음 단원으로의 브릿지 역할을 할 수 있도록 구성합니다.
>   - 새 개념의 도입 이유나 후속 학습과의 관계가 순서만으로 드러나지 않는 곳에 작성합니다. 이미 학습 내용에 충분히 설명했다면 중복하지 않으며, 형식적으로 값을 채우지 않습니다.
> - **시수**: 요약 표에는 학습 항목별 권장 시수와 단원 대비 비율, 강의와 실습 소계 및 합계를 적습니다. 본문에는 시간만 표시합니다.
> - 각 학습 항목은 강의 또는 실습 하나의 유형으로 작성하고, 표와 본문의 순서, 제목, 유형, 시수를 일치시킵니다. 모든 개념을 같은 제목과 시간의 강의–실습 쌍으로 만들 필요는 없습니다.
> - **학습 내용 (What)**: 다룰 핵심 내용을 요약합니다.


| 순서    | 주요 학습 개념 | 유형         | 권장 시수 | 비율   |
| ----- | -------- | ---------- | -----: | ----: |
| 1     | {개념}     | 강의 (또는 실습) | N시간   | N%   |
| 강의 소계 |          |            | N시간   | N%   |
| 실습 소계 |          |            | N시간   | N%   |
| 합계    |          |            | N시간   | 100% |


항목별 시수는 수업 구성 시 참고할 권장 배분이며, 단원 총 시수 안에서 학습자의 이해도와 실습 진행에 따라 조정할 수 있다.

각 실습의 권장 시수에는 수강생의 문제 해결과 강사 해설을 포함하며, 한 항목당 1.5시간 이내로 진행한다.

## 교재 제작 참고 사항

> 실습에 필요한 환경, 코드, 데이터 등의 리소스와 교재에 포함할 설치, 사용, 복구 등의 안내를 구분합니다. 준비 주체는 합의된 경우에만 적습니다. 위 항목에서 다루지 못했지만 교재 제작 시 신경 써야 할 내용을 작성해 주세요. 예를 들어 특정 도구나 버전 제약, 흔한 오개념, 수강생이 자주 혼동하는 부분, 결정이 필요한 사항 등이 해당됩니다.
