# project

프로젝트 구조와 지식 문서를 구성하고 관리하는 플러그인입니다.

| 스킬 | 역할 |
| --- | --- |
| [init-module](skills/init-module/SKILL.md) | 모듈을 초기화하거나 프로젝트 지식을 docs/로 이관·갱신 |

```bash
codex plugin add project@usnack-skills
```

마켓플레이스 등록과 개별 스킬 설치는 [저장소 안내](../../README.md)를 참고합니다.
설치 후 `init-module 스킬로 ./my-module을 초기화해줘`처럼 요청할 수 있습니다.
